# Repository Audit

This audit records what the current repository can safely claim for a job portfolio or Research MSc application. It is based on code, configuration, wrappers, and local documentation. It does not claim task success rates or model superiority unless a curated benchmark exists.

Status meanings:

- `STABLE`: maintained path and used as the primary baseline.
- `IMPLEMENTED`: code path exists and is wired into the repository.
- `EXPERIMENTAL`: active branch or deployment path exists, but behavior or evaluation is still under study.
- `TRAINING_ONLY`: training/data path exists, but no online robot path was confirmed.
- `WIP`: planned or partial work.
- `DEPRECATED/ARCHIVE`: retained for history or upstream compatibility.
- `UNKNOWN`: not enough evidence to make a public claim.
